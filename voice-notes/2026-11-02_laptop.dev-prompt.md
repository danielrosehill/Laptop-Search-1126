# Laptop Requirements Specification & Selection Brief

## Goal: Define the ideal hardware specifications, features, and constraints for a replacement laptop to support heavy terminal-based AI development (Claude Code), local ASR (Hebch/Parrot Key), and daily developer workflows.

## Context:
- **Current Machine:** Lenovo ThinkPad E15 (AMD CPU, 16GB RAM, 500GB/1TB storage).
- **Issues with Current Machine:** Broken arrow keys, broken trackpad (suspected 15-month-old son, though keypad failure predates him), insufficient RAM, storage running out, poor webcam, poor durability despite being a ThinkPad.
- **Operating Environment:** Ubuntu + KDE running in the terminal (console, spelled with a K).
- **Primary Workloads:** 
  - Heavy terminal usage (constantly running 4 to 8 parallel Claude Code sessions).
  - Constant voice recognition via local AI model "Hebch" (fine-tune of Parrot Key) running on CPU.
  - Occasional use of GIMP, Audacity, CadenLive (video/audio editing), VS Code, and a Windows VM.
  - Future/Aspirational use: Local on-device AI agent for routine Linux operations (cleaning directories, BTRFS restore copies, network/Tailscale fixes).
- **Purchasing Context:** Being decided as part of a family budget. Purchase channels under consideration: buying locally in Israel (higher price/smaller selection) or buying abroad in the US (better selection, warranty cover concerns). No pre-installed OS needed (user installs Ubuntu manually).

## Requirements:

### Core Requirements (Tier 1)
1. **RAM:** 32GB conservative, 64GB preferred to match desktop-level performance and handle multiple concurrent terminal/AI workloads without hitting resource limits.
2. **Storage:** Minimum 2TB NVMe SSD to avoid constant space constraints with VMs, code, and backups.
3. **CPU / AI Inference:** Sufficient CPU and integrated GPU performance to run local ASR (Parrot Key / Hebch) smoothly without lagging, and capable of handling basic video/audio rendering or upscaling at a push.
4. **Form Factor:** 15.6-inch display.
5. **Connectivity & Ports:** 
   - USB-C charging (essential).
   - Good dock/periphery pairing support (given modern minimal port scaffolding, reliable docking station ecosystem is critical).
6. **Built-in Hardware:**
   - Decent built-in webcam for Zoom calls (does not need to be 4K, just not terrible).
   - High-quality built-in microphone (beam-forming or high quality) optimized for ASR dictation.
   - Integrated e-SIM at the motherboard level.
   - Wi-Fi 7 (or the best available Wi-Fi receiver) and built-in Bluetooth.
7. **Keyboard & Input:**
   - Backlighting (subtle luminescence for nighttime/parenting use in low light).
   - ~6 extra assignable/macro keys (or a layout that accommodates custom shortcuts for Push-To-Talk/tap pattern, retake, delete, send for transcription, and Claude Code text emulation) to replace an external macro pad.
8. **Brand & Reparability:**
   - Zero brand loyalty; explicitly turned off by current ThinkPad experience.
   - If two options have equal spec value, prioritize the brand that emphasizes the availability of spare parts and high reparability.

### Secondary Requirements (Tier 2 / Nice-to-Have)
9. **Display Outputs:** Integrated HDMI port(s) or robust multi-display support via dock.
10. **Durability & Build:** High durability to last an expected usage period of 3 to 5 years without component failure.

### Advanced / Stretch Requirements (Tier 3)
11. **Storage/RAID:** Multiple storage slots supporting RAID configurations for advanced backups.
12. **Dedicated GPU:** Decent on-board GPU for advanced local tasks.
13. **NFC:** Built-in NFC tag writer support for inventory systems.

## Open questions:
- **RAM Acquisition:** Whether to buy 32GB built-in and upgrade later versus baking in 64GB upfront, navigating the current high cost of RAM ("RAM apocalypse").
- **Purchase Location:** Weighing local purchase in Israel (convenient, overpriced, limited selection) versus buying in the US (wide selection, warranty complications).
- **Port Selection:** Whether any modern laptops still offer dual HDMI outputs or if a single USB-C dock is the accepted standard.

## Out of scope:
- **Gaming:** No gaming or heavy graphics rendering required.
- **Pre-installed Operating System:** Pre-installed Linux/Ubuntu is explicitly *not* an advantage, as the user will wipe and install their own config.
- **RGB Lighting:** RGB lighting is explicitly disliked (backlighting is for utility/illumination only).
- **Text-Generation Local LLMs:** Running local LLMs for batch inference or chatting is out of scope (focus is strictly on local ASR and on-device agentic CLI tasks).
